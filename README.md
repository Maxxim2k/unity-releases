# Unity releases

Installers and update files for Unity, the float tank control software from Superior Float Tanks.

`stable.txt` and `test.txt` name the current release on each track. Each `.sig` file is its signature. Unity checks the signature before it installs anything, so a change to either file makes Unity refuse it.

Installers are attached to the [GitHub Releases](https://github.com/Maxxim2k/unity-releases/releases) on this repository.
